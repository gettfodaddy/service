# VPN Studio — основа бота и админ-панелей

Это отдельный проект, не связанный с базой Bedolaga. Он содержит:

- Telegram-раздел `/admin`: список и создание тарифов, редактирование параметров, выбор внутренних сквадов Remnawave, публикация, синхронизация сквадов и выдача одноразового кода входа на сайт.
- Веб-панель администратора: те же тарифы и сквады, обзор и журнал изменений.
- Пробный тариф-черновик: 1 день, 20 ГБ, 1 устройство. Сначала нужно выбрать сквады, затем опубликовать.
- Общую базу данных для двух интерфейсов. Сайт доступен только администратору из `ADMIN_IDS`; вход по одноразовому коду, который выдаёт бот.

**Текущая граница реализации:** проект управляет каталогом тарифов. Выдача подписок, заказы, ЮKassa, бонусный баланс и реферальные начисления ещё не подключены. Публикация тарифа пока делает его доступным в базе; пользовательский сценарий покупки не реализован. Слова «новые покупки и продления» в интерфейсе описывают выбранное правило для будущего модуля заказов.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`.
2. Заполните `BOT_TOKEN`, свой Telegram ID в `ADMIN_IDS`, длинный случайный `APP_SECRET`, URL и новый API-ключ Remnawave. Не используйте токен Bedolaga или ранее опубликованный токен.
3. Для локального Docker задайте `POSTGRES_PASSWORD` и оставьте `COOKIE_SECURE=false`, затем запустите `docker compose up -d --build` из этой папки.
4. Откройте `/admin` в новом Telegram-боте → «Код для сайта».
5. Откройте локально `http://127.0.0.1:8000` и введите код.
6. В «Сквады» нажмите «Синхронизировать». Теперь можно создавать тарифы и назначать им сквады.

Веб-сервис в Docker слушает только `127.0.0.1:8000`. Для отдельного VPS, домена, HTTPS и Caddy используйте [инструкцию развёртывания](DEPLOY.md). На публичном домене установите точный `WEB_ORIGIN` и `COOKIE_SECURE=true`; порт `8000` наружу не открывайте.

## Данные и границы

- `tariffs` — название, описание, трафик, устройства, порядок и статус.
- `tariff_periods` — срок и цена в копейках.
- `tariff_squads` — выбранные UUID внутренних сквадов Remnawave.
- `squad_cache` — актуальный список сквадов; исчезнувшие сквады помечаются и видны в панели.
- `audit_events` — журнал действий администратора.
- `login_codes`, `web_sessions` — авторизация сайта.

При подключении продаж отдельные таблицы `orders` и `order_snapshots` зафиксируют цену, параметры и сквады на момент покупки. Редактирование тарифа будет влиять только на будущие заказы и продления. Применение сквадов к уже активным подпискам будет отдельной операцией с подтверждением.

## Следующие модули

1. Пользовательские экраны: триал, каталог, «Мой ключ», инструкция, поддержка.
2. Создание и продление пользователя в Remnawave без изменения чужих подписок.
3. ЮKassa: тестовый магазин, заказы, webhook, повторные доставки, сверка статуса, возвраты.
4. Бонусный ledger: 1/3 суммы первого оплаченного заказа приглашённого, однократное начисление, частичное списание при продлении.
5. Миграция действующих клиентов с сохранением ссылок после отдельной сверки с Bedolaga.

Перед рабочим запуском нужны миграции БД и резервное копирование. Текущий `create_all` подходит для новой тестовой базы.
